# v0.8.1

_Release date: 2026-07-26_

Hotfix for connecting to a Lemonade server that enforces an API key.

## Fixed
- **API key auth** ([#29](https://github.com/siavashhub/lemonade-stand/issues/29)):
  the server-status probe and other direct server calls now send the
  `Authorization: Bearer <key>` header. Previously these hand-rolled requests
  bypassed the OpenAI SDK, so a server launched with `LEMONADE_API_KEY` answered
  `/api/v1/health` with `401` and the app showed as offline. Unauthenticated
  local servers are unaffected. (thank you @Neokeek)

## Security
- **brace-expansion** ([GHSA-mh99-v99m-4gvg](https://github.com/advisories/GHSA-mh99-v99m-4gvg)):
  pinned the transitive `brace-expansion` dependency to `5.0.8` via an npm
  `overrides` entry, clearing a high-severity denial-of-service advisory
  (unbounded expansion causing an out-of-memory crash).

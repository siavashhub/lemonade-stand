# v0.9.0

## Added
- **Reply Length Cap** configurable `max_completion_tokens` (env + persisted setting) that bounds runaway reasoning/output
- **Reply Cap UI** status-bar control + popover to set or disable the reply cap live, next to the context-size control

## Fix
- **Overthinking Generations** cap the reply so a ruminating reasoning model can't generate until it exhausts the context window
- **Missing Image Model** a failed image generation over an unavailable model now gets a decisive list/retry/stop instruction instead of the model ruminating on the raw error

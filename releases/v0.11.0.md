# v0.11.0

## Added
- **Schedule tasks from chat** the agent can now create Pitchers (scheduled tasks) for you when you ask, e.g. "every morning at 8, fetch example.com and summarize the headlines."
  - Built-in `create_pitcher` tool: the agent *proposes* a task and opens a pre-filled Pitcher editor for you to review, no task is scheduled until you save it
  - **Tools pre-selected, you confirm**: the agent pre-checks the tools the task needs (filtered to ones that actually exist), and you review and can change that whitelist before saving, the agent can never grant a task tools without your confirmation
  - **Confirm the trigger** and prompt in the editor before saving
  - **Safe by design**: scheduled pours can't create or edit other scheduled tasks (only interactive chat can), so a task can never schedule more work or escalate its own permissions

## Fixed
- **Failed scheduled runs are now visible** a Pitcher that fails (e.g. it needs a tool that wasn't enabled) is now correctly marked as failed instead of silently recording an empty "no reply" run. Every pour , success or failure , saves a conversation you can open to see the tool calls, blocked tools, and the exact error, both from the Pitchers panel (which now shows the error text and an open-run button) and in History.
